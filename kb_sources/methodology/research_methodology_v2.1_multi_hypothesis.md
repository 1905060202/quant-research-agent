# 方法论 v2.1：多假设竞争 + 全面性泛化

## 发现的问题

### 具体案例：63 张截图分析

**v2.0 的推理**：

```
事实: DF说63截图"不可能在PS5上实时运行"
结论: 这是PC开发环境渲染 → 展示引擎上限 → 主机目标是Trailer 2级别
```

**问题**：我只有一个假设。当一个假设通过了"合理"的直觉检查，我就停止了。

**应该探索的假设空间**：

```
H1: PC开发环境渲染(DF结论) — 最保守
H2: PS5 Pro + PSSR超分 — AI upscaling从低内部分辨率重建4K
H3: 基础版PS5但用了照片模式 — 非实时，静态渲染
H4: PS5实机但画质设置远超最终游戏 — 开发版无帧率限制
H5: AI渲染优化让PS5能做到这个水平 — ML超分+AI降噪+动态分辨率
H6: 混合 — 部分截图是PC，部分是主机
H7: Rockstar在测试不同平台的画质上限 — 63张分散在多个硬件上
```

对每个假设，需要评估：
- 证据支持度
- 证据反对度
- PS5硬件极限分析（GPU算力、带宽、RT核心性能）
- AI工具的边界（DLSS/PSSR能把多低的分辨率拉到4K？）
- 开发成本含义
- 如果这个假设为真，对最终游戏意味着什么
- 需要什么新信息来确认或排除

### 根本缺陷

**在推理的关键分叉点，我没有生成竞争假设。** 不是"选了错误的假设"——而是"根本没意识到还有其他假设"。

这个缺陷不仅出现在 63 截图分析。它在整个 GTA 6 研究和其他研究任务中都存在：

- 延期原因：只推演了"AI 上移目标" → 没考虑"传统打磨"、"领导层变动"、"疫情滞后影响"、"引擎重写"
- 预载 7 天：只推演了"文件大" → 没考虑"服务器容量限制"、"错峰下载策略"、"认证流程延迟"
- Lucia 是故事中心：只推演了"性别反转叙事" → 没考虑"市场策略"、"演员档期"、"双主角权重自然倾斜"

## 修补：多假设竞争框架（Phase 4.5）

在 Phase 4（多流认知推理）和 Phase 5（综合）之间，插入 **Phase 4.5：假设空间探索**。

### 触发条件

当遇到以下类型的推理分叉点时，必须执行 Phase 4.5：

| 分叉点类型 | 例子 | 为什么需要多假设 |
|-----------|------|-----------------|
| **歧义事实** | 63 截图的平台身份 | 多个合理解释，单一假设有偏见风险 |
| **因果推断** | 延期的原因 | 多种因素可能共同作用 |
| **动机推断** | 为什么选择佛罗里达 | 可能有多个战略动机 |
| **技术可能性** | PS5 能否跑某画质 | 技术边界本身不确定 |
| **未来预测** | Online 2.0 上线时间 | 多个变量影响最终决策 |

### 执行步骤

**Step 1: 穷举假设空间**

问自己：
- 还有哪些可能的解释？
- 如果我现在的假设是错的，最可能的替代是什么？
- 有没有"混合"的可能（多个因素共同作用）？
- 有没有"边界情况"（部分真部分假）？
- 别人的分析中提出了什么我没考虑的假设？

生成至少 3-7 个竞争假设，包括：
- 最保守的（主流观点）
- 最激进的（技术乐观派）
- 最悲观的（怀疑派）
- 混合的（多因素）
- 最有趣的（即使不太可能但值得思考）

**Step 2: 对每个假设做"压力测试"**

```
H(n): [假设描述]

支持证据:
  1. [来自一手源的直接支持]
  2. [来自二手源的间接支持]
  3. [来自类比/模式推理的支持]

反对证据:
  1. [矛盾的事实]
  2. [逻辑漏洞]
  3. [需要但缺失的证据]

硬件/技术边界分析:
  - 如果涉及硬件: GPU算力/TFLOPS、带宽、RT核心性能、显存
  - 如果涉及AI: 超分倍数上限、降噪质量/性能折衷、帧生成限制
  - 如果涉及成本: 开发成本、计算成本、时间成本

如果H(n)为真 → 对最终产品/决策意味着什么？
排除H(n)需要什么新信息？
```

**Step 3: 综合判断**

- 不是选一个假设——是**给每个假设赋置信度权重**
- 标注关键分歧点："这个判断取决于[假设X]是否为真。如果[假设X]错了，那[推论Y]也需要修正"
- **保留不确定**——如果证据不足以区分假设，明确说"目前无法确定"，而不是硬选一个

**输出**：每个关键推理分叉点的竞争假设矩阵 + 置信度分布 + 不确定性标注

## 泛化：从 GTA 6 到任何分析任务的全面性检查

### 全面性缺失的常见维度

| 维度 | 缺失表现 | 修复 |
|------|---------|------|
| **技术** | 只看软件不看硬件极限 | 查硬件spec→计算理论性能上限→对比目标画质 |
| **经济** | 只看开发成本不看机会成本 | 问"不做这个会怎样？""做这个的替代方案是什么？" |
| **时间** | 只看一个时间点不看趋势 | 向前推（这之前发生了什么）→向后推（这之后会发生什么） |
| **空间** | 只看一个区域不看全局 | 对比：其他工作室/其他平台/其他地区怎么做 |
| **因果** | 只看一个原因不看多因素 | 列所有可能的原因→对每个评估贡献度 |
| **视角** | 只用自己视角不换位 | 开发者的视角/玩家的视角/投资人的视角/竞争者的视角 |
| **假设** | 只生成一个假设就停止 | Phase 4.5 多假设竞争 |
| **边界** | 不标注"在什么条件下这个推理成立" | 每条推理标注适用条件和失效条件 |

### 新的分析前自检（Phase -1 增强）

在开始分析前，先填一份"全面性检查表"：

```
分析主题: [ ]
我默认的视角/假设是什么？[ ]
我需要考虑哪些替代视角？[ ]
  技术视角: [ ]
  经济视角: [ ]
  用户/消费者视角: [ ]
  竞争者视角: [ ]
  历史视角: [ ]
  未来视角（6个月/2年/5年后怎么看）: [ ]
这个分析中，硬件/物理/数学的硬约束是什么？[ ]
这个分析中，哪些结论取决于哪些关键假设？[ ]
如果我错了，最可能错在哪里？[ ]
```

## 回到 63 截图——演示多假设框架

### 事实
- 2026.06.24: 63 张 4K 截图发布
- DF 判断：组合原生 4K + 全 RT 反射 + 逐缕头发 + 体积效果 → "不可能在 PS5/XSX 上实时"
- 2025.05.07: Rockstar 确认 Trailer 2 "全部在基础版 PS5 上实机录制" (~1440p/30fps)

### H1: PC 开发环境渲染（DF 主流结论）
- 支持：DF 专家判断，像素数+效果组合确实接近主机极限
- 反对：Rockstar 在 Trailer 2 时主动声明"基础版 PS5 实机"——如果 63 截图是 PC，为什么不标注？
- 含义：最终主机画面低于截图水平。PC 版是"完全体"
- 排除条件：如果最终 PS5 版画面接近截图水平

### H2: PS5 Pro + PSSR 超分
- 支持：PSSR 可以从 ~1080p 内部超分到 4K，质量接近原生 4K。PS5 Pro 的 RT 性能比基础 PS5 强 ~2-3x
- 反对：DF 说"即使在 PS5 Pro 也不太可能"——但 DF 也不确定
- 硬件分析：PS5 Pro ≈ 16.7 TFLOPS (RDNA 3.5)，PSSR 超分 2-4x 倍率。从 ~1080p 内部 + PSSR → 输出 4K 是可能的，但加上全 RT 反射...仍很极限
- 含义：PS5 Pro 可能有 4K/30fps 模式。基础 PS5 是 ~1440p/30fps

### H3: 照片模式（非实时）
- 支持：静态画面可以开更高画质，无帧率限制
- 反对：如果只是照片模式，Rockstar 通常会标注"照片模式截图"
- 含义：不代表实际游戏画面

### H4: 实机但画质设置远超最终游戏
- 支持：开发版可以关闭帧率限制、调高所有参数。Trailer 2 被确认为实机（~1440p/30fps），截图可能是同一硬件但不同设置
- 反对：DF 认为差距太大——不只是"调高参数"能解释的
- 含义：最终游戏画质介于 Trailer 2 和截图之间

### H5: AI 优化让 PS5 能做到（技术乐观派）
- 支持：PSSR/DLSS 的快速进化、AI RT 降噪的成熟、动态分辨率技术的改进——综合起来可能让 PS5 跑到超过预期的画质
- 反对：基础 PS5 的 GPU ≈ 10.3 TFLOPS (RDNA 2)，RT 核心性能有限。全 RT 反射+逐缕头发+体积——即使有 AI 辅助，硬件极限仍是硬约束
- 硬件分析：PS5 的 RT 核心性能约等效 RTX 2060-2070 级别。全 RT 反射在 RTX 3070 以上的 PC 中才能稳定 60fps。PS5 做 30fps 全 RT 反射——理论上 AI 优化可以做到，但大概率要大幅降低内部分辨率
- 含义：最终 PS5 版可能是动态 ~1080-1440p 内部 + PSSR → 4K 输出 + 30fps。接近 Trailer 2，但不如截图

### H6: 混合——多硬件分批拍摄
- 支持：63 张不是一个小数目。可能在多个开发机上拍摄——部分 PS5，部分 PC，部分 PS5 Pro
- 含义：不能把 63 张视为单一平台

### 综合判断

```
我的置信度分布:
  H4 (实机高设置): 30% — 最可能。同一硬件不同设置
  H5 (AI优化让PS5做到): 25% — PSSR的突破可能被低估了
  H1 (纯PC): 20% — DF的判断有道理但有不确定性
  H2 (PS5 Pro): 15% — 可能但DF存疑
  H6 (混合): 10% — 逻辑上合理但无法验证
  H3 (照片模式): <5% — 不太可能不标注

关键不确定性: PSSR的超分上限是多少？AI RT降噪能把PS5的RT性能等效提升多少？
最终验证: 11月19日游戏发售后，DF会做"截图 vs 实机"对比分析。
```

## 这个修补为什么重要

不只是"63 截图分析应该更好"。而是：

**如果我缺少多假设框架，我的所有分析都在系统性偏向"最合理的单一解释"。这个偏向在我不知道的时候让我丢失了大量洞察，而且——更危险的——让我对自己的结论过于自信。**

用户指出的是 63 截图这一个案例。但同一个缺陷在全文的每个推理分叉点都存在。这个修补解决的是一类问题，不是一个点。
