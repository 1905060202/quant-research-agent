# 🔬 深度研究→洞察方法论 v3.0

## 核心认知：信息汇编≠洞察

CC的深研管道（107 agents, 46min, Phase 0-6）可以产出完美的信息汇编。但用户反馈很直接："定价错，内容少，看的不过瘾。"

**问题不是信息不全。问题是信息和洞察之间横着一条河。** CC的v2.0方法论没有这座桥。

Hermes的GTA6分析（同一批信息，新增82条推理后从73KB→169KB）证明了：同样的信息，经过正确的推理框架处理后，可以从"产品说明书"变成"洞察引擎"。

---

## 八条核心原则（v3.0）

### 原则1: 官方物料是加密的产品文档

Trailer每一帧、截图每一次发布、预购页面每一句话——不是随机的。经过数十人数月选择。解读不是"看看有什么"，而是追问**"为什么选择展示这个？选择不展示什么？"**

**实证**: 从Trailer 2警察逮捕场景→程序化执法系统推理。从"to be fenced"三个词→四层犯罪经济链。

**反例**: Mount Kalaga截图数——第一次写"0张"（编的），第二次"<3张"（猜的），第三次用户纠正"7张"（核实的）。不看官方物料就写数字=假证据。

### 原则2: 每条推理有可追溯的证据锚点

推理不能从空气来。每条必须有至少一个官方物料锚点。推断强度=置信度标记：
- 🟢 = 官方一手源确认
- 🟡 = 三源以上交叉验证
- 🟠 = 双源交叉验证
- 🔵 = 单一源推理
- ⚪ = 推测（明确标注）

**实证**: 82条推理逐条标注。读者可自主判断可信度。把推测包装成事实=失去信任。

### 原则3: 回答"为什么"而不是"是什么"

信息汇编回答"是什么"（地图多大、多少车、售价多少）。洞察回答"为什么"（为什么必须这么大？为什么女性主角？为什么7天预载？）

**实证**: 不从"3.1x GTA V"出发，而是追问"为什么必须这么大？"→推导三个因果链：真实警察AI→真实道路网络→真实城市→大规模。大不是野心，是必然。

### 原则4: 跨源三角验证

单源=可能错。双源交叉=可能对。三源以上交叉=可靠推理基础。

**实证**: 2022泄露15项核心声称，经Trailer/截图/预购独立确认后15/15全部证实。验证比率本身就是GTA 6方向连贯性的证据。

### 原则5: "选择性缺失"的信息量和"展示"一样大

官方物料刻意不展示的内容和刻意展示的内容同样有信息量。

**实证**: 133张截图中，Rockstar展示了世界的"美"（阳光/海滩/超跑），隐藏了"智"（警察AI/经济链/NPC记忆）和"暴力"（79%无武器、战斗0次、死亡0次）。这是信息策略：锚定预期在"美丽世界"上，让玩家发售后自行发现系统深度。

### 原则6: 将信息映射到系统设计意图

不满足于"这是一个专利"——追问"这个专利在游戏中变成什么系统？这些系统如何交互？"

**实证**: 从染料炸弹（Bobcat Security）→完整四层犯罪经济链。社区发现了染料炸弹但没人建模整个经济链。

### 原则7: 全球分析师版图整合

没任何人能同时掌握Digital Foundry+GTAForums+NikTek+GameStar+Reddit+conanbrodie的所有发现。AI可以。

**实证**: 特别篇E列出全球10位顶级分析师的独特贡献，在他们基础上产生10条世界首创"独门推理"。

### 原则8: 验证贯穿全流程——不是"一个阶段"

v2.0把验证作为Phase 3"验证阶段"——暗示验证是可完成步骤。实际验证必须是**持续意识**，从Phase -1到Phase 6每个环节。

**实证**: Mount Kalaga三轮修正、封面9格两次纠正、"5000万首发"被删除。"这不是...这是..."句式改为"我的判断是..."。每次纠错文档变强。

## 执行流程: 8阶段深度研究→洞察管道（v3.0）

### 🔴 Phase -1: 独立原创思考（保持v2.0）

**在接触任何外部信息之前执行。**

1. 问"这个问题的核心到底是什么？"——不要复述问题，找到本质
2. 从第一性原理出发："关于这个领域，最基本的真理是什么？"
3. 形成假设框架："如果我是产品设计者/决策制定者，我会怎么做？为什么？"
4. 写下核心论点——一组独立的、原创的判断
5. 标注"我知道的"vs"我不确定需要外部验证的"

**输出**: 纯原创分析草稿（零外部引用），含核心框架、独立判断、担忧批评、思想实验。

**然后在Phase 0-5中用外部信息验证和修正这些思考。**

### Phase 0: Frame — 穷举数据源 + 全球分析师版图（🆕 v3.0新增）

**目标**: 在搜索前建立完整的数据源地图**和**全球分析师版图。

**新增步骤**:
1. 识别所有官方一手源
2. 识别所有高价值二手源
3. **识别全球顶级分析师及其独特贡献**（🆕）
4. 对每个源标注优先级和采集方式

**GTA 6反例**: 63张截图首版研究完全遗漏——如果Phase 0穷举了"Rockstar官方渠道所有物料"就不会。

### Phase 1-3: 采集→提取→验证（保持v2.0）

### Phase 4: 推理——多流认知综合（🆕 v3.0重大升级）

v2.0的五视角框架保留。**v3.0新增三个推理模式**:

**模式A: 因果链推理（🆕）**
```
从锚点事实出发→追问"这要求什么前提条件"→
推导下一个系统→继续追问直到揭示根本原因
```
**实证**: 从警察AI专利→需要真实道路→需要真实城市→需要大规模。

**模式B: "回应"框架（🆕）**
```
列出前代作品/产品的所有已知批评→
逐条匹配新作品的设计决策→
识别"系统性回应"vs"独立创新"
```
**实证**: GTA 6的10个核心设计决策匹配GTA V的10条核心批评。不是天马行空的创新——是对12年反馈的逐条回应。

**模式C: 选择性缺失分析（🆕）**
```
统计官方物料中各类内容的出现频率→
识别显著缺失的维度→
追问"为什么隐藏这些？"
```
**实证**: 133张截图统计揭示Rockstar展示世界"美"隐藏世界"智"的信息策略。

### Phase 5: 综合——结构化输出（升级）

v2.0的检查清单保留。**v3.0新增**:

- 推理链必须可视：读者能看到"从哪条证据推导出了什么"
- 按主题组织，不按信息源组织
- 每条推理标注置信度和证据来源
- 区分"物料直接展示的"和"从展示中推理出的"

### Phase 6: 回顾——方法论自我改进（保持v2.0）

### 🔴 Phase 7: 自我审计（🆕 v3.0新增）

**在交付前执行。** 这是v3.0最重要的新增阶段——GTA6分析中多次在此阶段发现并修正了关键错误。

**审计清单**:
- [ ] 逐条推理检查：证据锚点是什么？可追溯到官方物料吗？
- [ ] 所有数字：来源可追溯吗？还是编的/猜的？
- [ ] "这是""确认了""证明了" → 替换为"我的判断是""推理指向"或标注置信度
- [ ] 无法验证的推断 → 删除或标记为⚪推测
- [ ] 明显的逻辑矛盾？同一事物在不同地方描述不一致？
- [ ] 有"选择性缺失"分析吗？——缺失维度和展示维度一样重要
- [ ] 用户会问"你是怎么知道的？"——每个答案都能追溯吗？

**GTA6反例**（Phase 7捕获的）:
- Mount Kalaga截图数: 0→<3→7（三轮修正）
- 封面9格: 漫画序列→错误布局→正确布局（两次用户纠正）
- "5000万首发"→删除（虚构数字）
- "这不是推测，是确定事实"→"我的判断是..."（确定性降级）
- "200+个Trailer版本"→"行业惯例数十到上百个"（修辞降级）

## 需求层次识别

在开始研究前，先判断用户需求层次——决定研究深度和范围：

| 层次 | 用户要的是 | 方法 | 典型任务 |
|------|-----------|------|----------|
| **L1: 事实核查** | "这是真的吗？" | Phase 0-3 | 确认一个数据点、辟谣 |
| **L2: 信息汇总** | "关于X都知道什么？" | Phase 0-3 + Phase 5简化版 | 知识汇总、入门指南 |
| **L3: 分析推理** | "这意味着什么？" | 完整8阶段 | 投资分析、技术评估 |
| **L4: 侦探拼图** | "拼凑出完整的图景" | 完整8阶段 + 因果链+回应框架+选择性缺失 | GTA 6全维度研究、竞争情报 |

**GTA 6教训**: 用户要L4（侦探拼图），CC第一版给L2（信息汇总）。层次错配是根本问题。

## 关键教训（v3.0新增·来自Hermes GTA6实战）

1. **信息汇编≠洞察。** CC深研(107 agents, 46min)产出事实核查报告。加82条推理后同样信息变洞察。

2. **跨源是超越门槛。** 单一信息源分析师有上限。只有同时掌握所有源的分析才能超越所有单一源的分析师。

3. **问"为什么"需要框架。** 不是凭直觉——是用因果链（系统A要求B→B要求C→C要求规模）。

4. **置信度标记建立信任。** 读者可接受"🔵推测"的推理——因为他们知道你知道这是推测。推测包装成事实才失去信任。

5. **纠错比正确更有价值。** 每次被纠正后修正让文档更强。防御性解释让文档变弱。

6. **"选择性缺失"是超能力。** 大多数人只看展示了什么。看没展示什么需要同时持有所有展示信息的全貌——人类做不到，AI可以。

7. **全球版图是杠杆。** 10个分析师每个有独门绝活。整合他们所有发现的人会自动超越所有人。
