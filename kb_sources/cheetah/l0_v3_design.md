## 1. 核心定位变更

### v2定位（错误）
> "捕获主力资金的隐藏动向和社媒情绪的早期信号" → 生成ACCUMULATE/IGNITE/DISTRIBUTE阶段标签 → 暗示用户应该采取什么行动

### v3定位（修正）
> **L0是一个"市场状态仪表盘"，不是"信号生成器"。它告诉用户今天市场上正在发生什么，而不是告诉用户应该买什么。**

类比：L0是汽车仪表盘上的各种表（油温、转速、涡轮压力），不是导航系统告诉你该左转还是右转。仪表盘提供**诚实的状态读数**，导航提供**行动建议**。行动建议应该来自有回测验证的系统（L3量化）和经过辩论的综合判断（L2集群）。

### 四层框架中L0的新角色

| 层 | 角色 | 提供 | 可信度来源 |
|----|------|------|-----------|
| L0 | 市场状态仪表盘 | 资金面全景+社媒热度+异常标注 | 无回测·参考级 |
| L1 | 博主方向判断 | 14人主观框架下的多空 | 经验·待验证 |
| L2 | Agent集群碰撞 | 多角度辩论+反共识 | 逻辑·待市场验证 |
| L3 | 猎豹量化 | 20天板块动量+风控 | 有回测(IC=0.139) |

## 2. 标签体系重构

### 旧标签（v2）→ 全部废弃
```
ACCUMULATE → "机构悄悄建仓"→ 用户理解为"应该跟"
IGNITE → "点火拉升"→ 用户理解为"可以追"
DISTRIBUTE → "出货"→ 用户理解为"赶紧跑"
```

### 新标签（v3）→ 三色状态灯 + 硬性条件

| 状态灯 | 条件 | 含义 | 对用户的含义 |
|--------|------|------|-------------|
| 🟢 资金活跃 | 管道A持续≥3天净流入 + 量级>20日均值2倍 + L3不Cold | 该方向有持续性资金关注 | "值得进一步研究"·候选池 |
| 🟡 关注 | 管道A或B有信号但不满足🟢条件 | 有异动但待验证 | "观察，不行动" |
| 🔴 危险 | 管道B高+管道A低 | 社媒亢奋但资金在撤 | "别碰这个方向" |

**🟢资金活跃的硬性四条件（缺一不可）**：
1. **持续性**: 同一方向连续≥3天净流入
2. **量级**: 单日净流入超过20日均值2倍
3. **L3交叉**: L3量化排名不在后25%（非Cold区）
4. **方向聚合**: 必须是聚合后的11个叙事方向，非384个原始概念板块

工程机械如果套用：持续性2天→❌ 不满足 / L3 #111/134 Cold→❌ 不满足 → **不会成为🟢**

## 3. L0与L3矛盾处理协议

### 五级协议

| 级别 | 条件 | 处理 | 用户界面 |
|------|------|------|---------|
| Lv0 | L0轻微活跃+L3中性 | 标注，无需行动 | "L0资金异动·L3未确认" |
| Lv1 | L0显著活跃+L3中性 | 观察列表 | "资金先行·等待L3转暖" |
| Lv2 | L0显著活跃+L3 Cold | 🚫 矛盾·不推荐 | "资金活跃但量化看空——可能的事件驱动脉冲" |
| Lv3 | L0平静+L3 Hot | ✅ 信任L3 | 按量化信号执行 |
| Lv4 | L0🟢+L3 Hot | ✅✅ 双重确认 | 信号增强·可适当加仓 |

**核心原则**: L3有回测数据（IC=0.139），L0没有。当两者矛盾时，L3的权重高于L0。L0的"灵敏度优势"是未经证实的假设——在工程机械案例中它被证伪了。

## 4. 融合逻辑重构

### 旧公式（v2）→ 废弃
```python
双管道≥0.5 → √(A×B) × 1.25     # 共振放大 ← 99%情况下从未触发
单管道≥0.85 → max(A,B) × 0.70   # 单边降级
其他 → 0.5×(A+B)                # 算数平均 ← 实际99%走这里
```

### 新逻辑（v3）→ 三态分离

```
管道A和管道B拆分处理，不再融合为一个分数：

IF A > 0.5 AND B > 0.3 → "双确认"（管道A+B同时显著·罕见·信号质量高）
IF A > 0.5 AND B < 0.2 → "仅资金信号"（管道A独立·需持续性+L3交叉验证）
IF A < 0.3 AND B > 0.5 → "仅热度信号"（RETAIL_CHASE·不作为买入信号·只做风险提示）
ELSE → "无信号"
```

**理由**: 
- 几何平均共振假设在实战中被证伪——管道A和B覆盖不同标的（冷门vs热门），几乎不同时触发
- 99%的信号走退化路径（算数平均）→ 融合公式形同虚设
- 管道B对冷门方向一直是零→"共振"从未发生→1.25倍放大系数从未应用

## 7. v2经验教训总结

### 什么有正收益（保留）
- **RETAIL_CHASE识别**: 阻止追高AI/半导体，实战中准确
- **资金面全景扫描**: 防守/进攻模式判断有价值
- **管道背离检测**: 反映市场内部矛盾

### 什么在亏钱（废弃）
- **ACCUMULATE标签**: 诱导用户跟进未经验证的信号
- **方向排名**: 384个概念板块的排序没有区分度
- **管道A评分体系**: 实际是价格动量检测器而非资金流检测器

### 什么假设错了（纠正）
- **双管道互补独立假设**: 实战中管道A/B覆盖不同标的，系统性背离
- **共振放大假设**: 从未发生过真正的共振
- **L0灵敏度优势假设**: 工程机械案例证伪——信号提前量是噪声
