## 二、关键认知

### 2.1 因子≠增量信息（今日最重要教训）

20个新因子单独测IC时15/20有|IC|>0.02, 但共线性检查后:
- 10个与现有因子 r>0.75 → 旧信息换包装
- 3个独立 (max_corr<0.5): ret_serial_corr_5d, skew_60d, kurt_20d
- 即使独立因子, 加入模型也无提升 → 同一数据源的信息已饱和

### 2.2 数据源 > 因子工程

四轮P0失败 vs P1管道一天建成——差距不在因子设计, 在数据维度。
OHLCV → 172因子 ≈ 天花板。龙虎榜/股东户数/机构评级 → 全新信息维度。

### 2.3 中性化陷阱

行业中性化特征 + 未中性化目标 = 特征-目标信息维度不匹配 → IC崩塌。
解法: 要么同时中性化目标, 要么不做行业中性化。

### 2.4 v10是当前约束下的局部最优

172因子+3层LGB+cap_tier中性化。继续在同一数据源上堆因子 = 边际递减甚至负增长。

## 四、实验纪律（今日确立并验证）

1. **备份优先** — 任何修改前先完整备份到 backups/
2. **隔离实验** — 新版本用新文件(features_vXX.py), 不动生产代码
3. **单变量对比** — 每次只改一个变量
4. **共线性必查** — 新因子 vs 现有因子的Spearman相关矩阵
5. **2-3次验证** — 独立subagent审计, 不一次输出就交差
6. **失败比成功更有信息量** — P0四轮失败精准定位了OHLCV天花板
7. **subagent饱和拆分** — 不设数量上限, 主线程只收敛不执行
8. **模板是起点不是边界** — Hermes task模板不能框死, 自主扩展维度
9. **信息源自判** — 模板指定的渠道可能过时, 自主评估替换

### 7.5 五个非对称优势（量化私募无法复制）

1. **Agent集群→量化信号**：14认知原型多视角碰撞 → 市场状态判断，纯数据驱动模式无法复制
2. **10人博主体系→散户情绪量化**：精品博主池的情绪/叙事因子，私募的微博/雪球舆情分析没有这个精度
3. **CC深度搜索→全球alpha发现**：跨语言搜索最新论文和Kaggle方案，私募的卖方研报+CNKI搜不到
4. **三层正交验证**：L1博主+L2集群+L3量化同时指向同一方向时，置信度远超单一模型
5. **小规模优势**：个人资金无冲击成本、可交易小盘、换手率更高

### 7.6 七个"不要做"（Opus明确警告）

| 方案 | 原因 | 证据 |
|------|------|------|
| Transformer替代LGB | 牛津2026实证：不如简单动量因子 | 样本量太小(152天) |
| 多周期ensemble | v9已验证IC=0.035 vs 纯20d IC=0.126 | 噪音混合 |
| 股票池扩到全A股 | v9已验证2512只→IC崩塌 | 微盘噪音 |
| TabNet | 无任何量化选股成功案例 | 文献为零 |
| 行业中性化 | v5三次验证IC从0.235→0.042 | A股预测力在板块共模 |
| 残差收益(Y-行业均值) | 同上 | 杀信号 |
| Warm-start增量训练 | 特征变1个就崩溃 | 全量重训5.5分钟更可靠 |

### 7.7 Opus对已有失败的新理解

- **行业中性化杀信号** → 正确做法是用市场状态条件化替代，让模型自适应学习行业效应权重
- **小盘IC=-0.002** → 小盘不应该和大中盘同模型，需要资金博弈特征+短周期目标
- **OHLCV因子已榨干** → 不是OHLCV信号穷尽，而是当前工程化方式已穷尽。同数据可提取非线性交互(AE)、跨股票特征(GNN)、资金流特征(尾盘/开盘)

### 8.2 第二轮：集成验证（20:42-21:30，已完成）

**方案**：构建 `features_v20_integrated.py`（879行，35KB），一个脚本跑完三个实验。

**结果**：

```
20日 IC 对比表：
┌─────────┬──────────┬──────────┬──────────┬──────────┐
│ Tier    │ v10生产  │ CC复现基 │ LambdaR  │ LR+宏观  │
├─────────┼──────────┼──────────┼──────────┼──────────┤

┌─────────┬──────────┬──────────┬──────────┐

│ Overall │  0.058   │ -0.053   │ -0.119   │
└─────────┴──────────┴──────────┴──────────┘
```

**关键发现**：

1. **LambdaRank 对大中盘是压倒性胜利**：Large +0.261（17倍提升），Mid +0.106（1.6倍提升）。两轮实验完全一致。

2. **LambdaRank 对小盘是灾难**：Small 从 -0.101 退化到 -0.169。小盘的排序信号比大中盘更弱，lambdarank 的 query group 内样本噪声过大。

3. **宏观特征在 LambdaRank 上是负作用**（与第一轮矛盾）：第一轮宏观加在 MSE 上时 Mid +0.048、Small +0.098。但加在 LambdaRank 上时 Large 从 0.277 退化到 0.122。根因：LambdaRank 已从数据中学到了隐式的市场状态信息，显式追加反而过拟合。

4. **CC 无法复现生产 baseline**：两轮实验，CC 从 features_v9.pkl 重新训练 MSE baseline，IC 始终为负（-0.096），而生产模型 hermes_weekly_v5.pkl 的 IC=0.126。可能原因：(a) 随机种子不同 (b) 数据切分的微妙差异 (c) 生产模型用了不同的 cap_tier 分类 (d) production pkl 中盲期 IC 的评估方式和 script 中不同。

5. **Overall IC 被小盘绑架**：小盘占股票数量大头，LambdaRank 对小盘的负作用拖累整体。但如果只看大中盘（我们实际交易的标的），LambdaRank 是明确的赢家。

### 11.3 LambdaRank 悖论（Opus 需要解决的核心问题）

**LambdaRank 对大中盘是仙丹，对小盘是毒药**。

为什么？我的分析（不是CC说的）：

1. **query group 样本量差异**：LambdaRank 需要 query group 内有足够的股票做 pairwise 比较。Large cap 每个日期 66 只（足够），Mid 也是 66 只（足够），Small 可能有几百只但信号极弱——噪声股票之间的 pairwise 比较没有信息量，反而引入噪声。

2. **信号强度差异**：大中盘的 20 日 forward return 有可预测的动量/趋势信号。小盘的 20 日收益主要由资金博弈驱动（游资进出），量价特征几乎无预测力。LambdaRank 在噪声上做 pairwise 排序 = 垃圾进垃圾出。

3. **MSE 对小盘更"宽容"**：MSE 预测接近均值时损失小，LambdaRank 必须明确排序——当没有排序信号时，MSE 至少不乱排，LambdaRank 强制乱排。

**可能的解法**（需要 Opus 判断）：
- 对小盘用不同目标周期（5日而非20日）？
- 对小盘用不同损失函数（MSE 保留，只用 LambdaRank 于大中盘）？
- 对小盘做更激进的流动性过滤（剔除日均成交额 < 5000 万）？
- 对小盘用不同特征集（资金博弈特征在 8.1 实验B中 CV IC=0.063 但盲期为 0——说明近期小盘市场条件与历史完全不同）？

### 11.4 宏观条件化的矛盾（需要 Opus 解释）

| 实验条件 | Mid Δ | Small Δ |
|---------|-------|---------|
| 第一轮：MSE + 宏观 vs MSE | +0.048 | +0.098 |
| 第二轮：LambdaRank + 宏观 vs LambdaRank | -0.095 | +0.092 |

宏观特征在 MSE 上帮助 Mid，在 LambdaRank 上伤害 Mid。对小盘的帮助在两轮中一致。

**我的假设**：LambdaRank 通过 pairwise 比较已经隐式学到了市场状态（同日股票共享相同的市场条件，pairwise 比较自然消除了市场状态的影响）。显式追加宏观特征反而引入冗余信息 → 过拟合。但为什么小盘不受影响？因为小盘 LambdaRank 本来就烂，宏观特征给小盘提供了额外的信号维度（小盘受市场风格轮动影响更大）。

## 十四、Phase 5: 最小差分实验 — LambdaRank真相（2026-05-26 上午）

> Opus 4.7 指令：在生产管道上做最小差分实验，只改loss function，冻结其他一切。

### 14.1 背景

5-25晚间LambdaRank实验显示大中盘+0.26的"压倒性胜利"。但Opus R4复审指出：CC基线IC=-0.096，生产基线IC=0.126，0.22的裂缝意味着所有"相对提升"不在可部署坐标系里。

Opus指令：拿生产 `features_v10.py`，**只改一行 loss function**（MSE→LambdaRank），其他全部冻结（seed/split/hyperparam/数据/特征），在生产管道上直接验证。

### 14.2 实验设计

| 维度 | v10生产 | 最小差分 |
|------|---------|---------|
| 数据 | features_v9.pkl | **相同** |
| 特征 | 172 neut_cols | **相同** |
| 目标 | 20d rank pct (连续) | 20d rank decile (整数0-9) |
| 模型 | LGBMRegressor(MSE) | LGBMRanker(lambdarank) |
| 超参 | tier-specific (large=400/mid=500) | **完全相同** |
| 分桶 | large/mid/small | large/mid only |
| Split | 5-fold purged CV, PG=30 | **相同** |
| Blind | 2026-04-01 | **相同** |
| Seed | 42 | **相同** |

脚本：`production/lambdarank_minimal_diff.py`（230行，从features_v10.py复制，仅改loss部分）
模型：`hermes_weekly_v10_lambdarank_minimal_diff.pkl`（153KB）
报告：`lambdarank_minimal_diff_report.json`

### 14.3 结果

**20日IC（主要指标）：**

| Tier | v5生产 MSE | LambdaRank | Δ |
|------|-----------|------------|------|
| Large | 0.207 | 0.234 | **+0.027** |
| Mid | 0.254 | 0.253 | -0.001 |

**5日IC：**

| Tier | v5生产 MSE | LambdaRank | Δ |
|------|-----------|------------|------|
| Large | 0.112 | 0.096 | -0.016 |
| Mid | 0.126 | 0.055 | -0.071 |

**CV IC：**

| Tier | CV Mean | CV Std | Folds |
|------|---------|--------|-------|
| Large | 0.060 | 0.111 | 3 |
| Mid | 0.094 | 0.067 | 3 |

### 14.4 关键发现

1. **LambdaRank +0.26 是管道假象**。之前的"压倒性胜利"绝大部分来自CC坏基线（-0.096）的裂缝。在生产管道上，Large仅+0.027，Mid零提升。

2. **5日线全面退化**。LambdaRank的pairwise排序在短周期上反而更差——5日噪声太大，强制排序不如MSE的回归平滑。

3. **CV IC波动大**。Large cross-validation IC从0.01到0.21，fold间方差0.11——LambdaRank对训练窗口构成敏感。

4. **Mid的"大规模胜利"是虚的**。之前FACTOR_ITERATION报告Mid +0.106（vs CC基线），实际vs生产基线是0。因为CC基线Mid=0.166而生产Mid=0.254，差值刚好是0.088——LambdaRank没有提升Mid，是CC基线本身比生产低。

### 14.5 结论

**不上LambdaRank。** +0.027的Large 20d改善不值得承担以下风险：
- 分数尺度不对齐（rank-order vs 期望收益率，合并时边界失真）
- 临界市值跳变（股票在cap_tier间漂移时信号跳变）
- Kill Switch重校准（阈值基于MSE分数分布）
- 5日信号退化（短期预测变差）

**当前v5 MSE在152天+OHLCV约束下是near-optimal。** 等P1数据积累（龙虎榜/股东户数/机构评级6-12个月历史）再重启架构迭代。
