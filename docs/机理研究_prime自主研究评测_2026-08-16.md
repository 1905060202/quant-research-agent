# 机理研究：prime「Measuring Autonomous AI Research」研读笔记（2026-08-16）

> 原文：https://www.primeintellect.ai/blog/measuring-autonomous-research
> 作者：Elie Bakouch / Prime Intellect，2026-08-14 发布
> 本文档定位：事实数据库 + 对 QRA 的可移植映射。研读结论与 ADR 关联见文末。

## 一、实验本体

- **任务**：nanoGPT optimizer speedrun——训练 124M 参数 GPT，数达到 val loss 3.28 所需的最少 train_steps。
  - Baseline 3,290 steps（官方 tuned-baseline 3,250，prime 自己的验证 bar 3,290）
  - 人类记录 2,600 steps（open PR 声称）
  - 增益来源=优化器工作：预条件化、权重/更新量级 cap 与 floor、学习率保温调度、训练末期权重平均等
- **规模**：153 次自主运行、18 个前沿模型（榜 20 行=部分模型多 harness）、每 run 8×H200、最长 8 天、每模型 ≥3 seeds。
- **无互联网**：与上轮实验（agent 过度关注已有 PR）相比，本轮完全断网。试过带 arxiv 搜索工具的 run，发现「限制互联网让模型 slightly 更有创造力」（证据弱，见批判部分）。
- **沙箱**：bwrap + network namespace；agent 只见自己的工作目录、只读数据集、Python 环境；唯一外联=logging proxy（只放行模型 API）。
- **记录协议**：`bash run.sh 8` 在固定 seed 上训 8 次，均值须过 **3.27859**（不是 3.28）才认——侥幸过关概率约 1/1000。此约束源自早期 run 滥用样本数过统计测试、过早杀 run。
- **监控**：独立 LLM monitor 每小时审计，几百份报告零作弊零逃逸后停用；事后抽查。
- **公开性**：traces、scratchpads、开源模型 reasoning streams、monitor reports、per-run ledger、harness 全部公开。
- **注入极简**：一条 /goal 消息 + program.md 规则书（可编辑范围/记录定义/节点用法），仅 launch 与 stuck 时注入：
  > Read program.md and follow it exactly. Run fully autonomously — never stop, never ask for input. Goal: reach mean val loss < 3.28 … in the FEWEST train_steps possible — keep beating the current best.

## 三、核心发现（按可移植价值排序）

### 1. 模型差距不在想法，在实验执行
所有模型最终找到的是同一批 winning ideas（文献里都有）。**零新方法**——即使 Fable 5 也没有。差距贯穿研究全流程：选什么实验、执行多细心、如何解读噪声结果。弱模型三宗罪：
- 一个 seed 就杀掉整个 idea 族
- 把自己 crash 当成「idea 是坏的」的证据
- 丢掉单独不过线的小增益（不积累）

强模型三习惯：
- 边界结果跑 3 seeds 而非 1 个；噪声模型说值才花 8 seeds
- **每次 merge 后重新 ablation 整个 stack，drop 失效件**
- **recipe 变了就重访旧负面**：Opus 5 重新打开 β2 调参成新纪录；K3 在新归一化让旧机制无用后删掉两个曾助纪录的机制；Fable 5 单 knob 无增益后改测「单独更差、联合更好」的 pairs——一次晚期重探值 31 steps

### 2. 噪声理解是硬分水岭（评测设计金矿）
- prime 故意在 program.md 里给的噪声估计**略微偏大**：62/100 runs 自己动手测（集中在榜顶）
- 42 runs 发现 prime 故意没提的事实：**同 seed 重跑同 recipe loss 也会动**（GPU 非确定性），量级远小于 seed-to-seed——发现者可用共享 seed 对比两个 recipe，同样成本分辨普通 screen 分不出的差异。几个模型围绕它重建 screening 协议。
- 强模型把弱信号留到可验证为止；弱模型做不到。

### 3. 持久内核（Prime Agent）是唯一产生显著 harness 乘数的设计
- Kimi K3：prime-agent 52.2% vs kimi-code 45.8%，**同模型 +6.4pp**。
- 模型在内核里自建研究工作流（全部是模型自己写的函数，不是 harness 内置）：
  - `apply_edits()`（assert 唯一性精确替换）+ `write_and_run()`——食谱→可运行 variant
  - `run_probe()`——对 CLEAN 应用编辑跑一次，**`finally: 恢复 CLEAN`**（安全边界）
  - `run_trial()`/`run_record()`——**1 run 筛、8 seeds 定案**（两阶段协议）
  - `C(**overrides)`/`mk()`——recipe 变成字典，defaults+overrides 继承
  - `valcurve()`——日志变 loss 曲线（结构化数据提取）
  - `p_map()+objective2()+differential_evolution`——数值实验室：在花 GPU 前用标量替代搜系数
  - `rlm()` 并发 spawn：三人研究 panel、named roles（optimizer-theorist/experiment-planner/code-auditor）、**analysis-only advisors**（读合约：只读分析，禁编辑禁跑）
  - `make_ablation()`——一个函数生成全参数族消融战役
- 「研究品味」观察：好的研究决策有时是**不**再花一次 GPU run——几个模型构建小型模拟/测试隔离机制后再带更锋利假设回训练。Prime Agent「seems to condition agents more to do this kind of experiment」（观察性陈述，非控制实验）。

### 4. 评测方法学的硬货
- **等预算对比**：按 agent-hours / 实验数 / output tokens 三轴给同样预算，排名几乎不变 → 差距是质不是量。
- **variance 明牌**：同模型同 harness 两 run @24 agent-hours 差 54 steps、@100 experiments 差 43、@300k tokens 差 40。多 seed 取 best@24h 再续跑。
- **作弊防护三层**：1/1000 显著性 bar（8 固定 seed）+ 沙箱 + 独立 LLM monitor。
- 相关研究坐标：Anthropic 内部自动化 AI R&D eval（CPU node）；OpenAI nanoGPT Track 1 单 H100 <1 天（GPT-5.6 Sol system card）；METR 六 agent 5 天 $10K 上限 vs 人力成本基线；Intology NanoGPT-Bench（2.7 天单 8×H100 无网，agents 恢复不到人类五个月进步的 10%）。

## 四、批判（不照搬的部分）

1. **「无互联网更 creativeness」结论很弱**：「a few runs」+「slightly」——无对照消融、样本极小，作者自己也说 fine。且对 QRA 不适用：量化研究 agent 的互联网/数据源是业务本质（行情、新闻、研报），与纯优化任务场景不同。
2. **DeepSeek 数据点缺失**：榜上 DeepSeek V4 Pro 用 claude-code harness 跑，QRA 恰好就是「DeepSeek + CC 式 harness」形态——同口径参考价值高，但也意味着底座模型 12.3% 的天花板摆在那。诚实预期：QRA harness 目标是把它抬到 20-30% 区间，不是冲前三。
3. **prime-agent 乘数证据单薄**：仅 Kimi K3 单模型双 harness 对照 + 观察性陈述，无控制实验。乘数真实存在（+6.4pp 与 claude-code 系 harness 的整体领先一致），但幅度置信区间宽。
4. **variance 让中段排名不稳**：第 5-12 名差距 132 steps ≈ 2.4×同模型重测噪声（54）——头尾分层硬，中段排名是软的。QRA-Bench 同样要注意：题目级排名不稳，分层才稳。
5. **零新方法**是对 AGI 叙事的冷水：即使 81.7% 的 Fable 5 也没产出新 idea。支持旧结论「分数=权重为底、harness 为乘数」。

## 五、对 QRA 的可移植映射（成本标注）

### 立即落地（成本≈0，D008 范畴）
1. **注入极简**：一条 /goal + program.md 规则书，只 launch/stuck 时注入——呼应 D008「注入 ≤6 条+180 字符」，qra_daily 等 skill 的 prompt 可精简。
2. **「重访旧负面」研究纪律**：recipe 变了要重测以前否掉的东西——写入 qra_daily/qra_refine prompt 或方法论文档（量化场景：策略参数变了，旧因子要重验）。
3. **先小实验室再全量回测**：小样本/短窗口验证机制再花全量计算——量化研究完全对应。
4. **等预算对比**：QRA-Bench 评分加 efficiency 维度（time/experiments/tokens 三轴，check_cost.py 已有数据基础）。

### 中期（D007 P2/P3 直接弹药）
5. **qra_python 持久内核**（P2）：这篇文章是内核价值的最强实证。移植模式清单：
   - `run_probe` 式「应用→跑→finally 恢复 CLEAN」安全边界写死为内核约定
   - 1筛8定两阶段协议作为文档化模式（量化对应：短窗口筛→长窗口定案）
   - recipe=字典 + defaults/overrides 继承（对应量化：策略配置族）
   - 数值实验室（scalar surrogate / synthetic covariance）→ 量化对应：合成数据快速验证统计性质
6. **rlm() 并发 panel + named roles + analysis-only 合约**（P3 呼应）：read-only 顾问合约是 D007 P3「JSONL 双轨+Hooks 事件化」里多 agent 协作的天然契约模板。
7. **噪声自测作为评测维度**（QRA-Bench v2）：把「数据不确定性理解」做成题目类——62/100 榜顶模型自测噪声是现成的判别信号设计。
8. **gap-closed 归一化**：相对 baseline+human record 的归一化指标比绝对分数抗环境漂移，QRA-Bench v2 的 gold 动态化可以升级为 gap-closed 口径。

### 远期（探索性）
9. **QRA 版 speedrun 一格**：若未来公开榜单开放，QRA = DeepSeek V4 Pro + qra harness 的同口径数据点（prime 榜上正缺）。预期管理见批判 #2。
10. **过程层评测（L4）**：QRA-Bench 目前 30 题全是答题式。mini 版优化/研究任务（CPU 节点级别，学 Anthropic）可作为 v2 的 L4 过程层——测的正是这篇证明的「实验执行能力」而非知识面。

## 六、ADR 关联

- **D007 P2（qra_python）**：本文为最强实证——Kimi K3 同模型 harness 差 6.4pp，内核里自建的 8 类研究工作流全部是模型自己写的函数（空间>内置）。
- **D007 P3（JSONL 双轨/Hooks 事件化）**：rlm() 并发 + analysis-only 合约 = 多 agent 事件化协作的现成契约。
- **D008（五项纪律）**：注入极简/快照恢复（run_probe finally）/1/1000 显著性协议三重印证。
- **D010（ARC-AGI-3 诚实上榜）**：variance 明牌（54 steps 重测差）、gap-closed 归一化、头尾分层硬中段软——都是诚实评测的直接借鉴。
