## 一、ARC-AGI-3 情报：三个颠覆性事实

### 1.1 "打满榜单"要重新定义

- **公开集（25 环境 183 关）已被打穿**：社区榜前四 Tycho 100% / Retrodict 99.86% / baseline1 99% / Schema 98.98%，全部开源可复现。榜首已是满分——**打榜打的是成本和排名，不是分数**。人类专家 harness 在公开集也只有 95.3%。
- **官方榜禁 harness**（技术报告 p.15："the official leaderboard will not use a harness to report official scores"），且只测 ARC Prize 主动选择的商用 API，第三方系统上不去。QRA 唯一官方认可路径：社区榜上榜 → 被选中验证 → 半私有集打分、公开/半私有两集成绩 ±15pp 一致性通过 → 上官方榜。
- **Kaggle（唯一打私有集的公开通道）对 QRA 关闭**：评测期断网（"Internet access disabled… no API-based systems"），DeepSeek V4 Pro 仅 API 形态，无法参赛。除非开放权重版本出现。私有集当前最高水平（Milestone 1 冠军）仅 1.21% RHAE。

### 1.2 prime 的真实成绩

- prime+Opus 5 = **95.5% RHAE（Best@1，公开集）**，三次全跑 95.0/95.2/95.5；官方 scorecard 记录中位数 **95.24%，178/183 关，24/25 环境，11,245 动作**。Best@3 声称 99.97% 但选择粒度未定义。
- **争议**：repo 缺 ARC adapter、提示词、运行日志、固定配置，无法复现；不在社区榜上（榜首是 Tycho/Retrodict/baseline1）。
- **最关键对照组**（prime 官方图）：同一 harness，Opus 5=95.5%、GPT-5.6 Sol=78.3%、GPT-5.6 Terra=25.7%、GLM 5.2=8.6%。**同 harness 换底模暴跌 17-87pp——底模决定上限，这条与 arc-code 研究结论一致，现在是三源互证。**

### 1.3 环境接口与评分（QRA 怎么接）

- **Python 包**：`pip install arc-agi` → `arc.make("ls20")` → `env.step(GameAction.ACTION1)`。不是只给图像。
- 轮次制：64×64 网格、16 色；观察=帧/帧序列（terminal 文本渲染或图像）；动作=5 个按键+Undo+选格（坐标），每环境是子集。
- **RHAE 评分**：每关 = min(1.15, 人类基线动作数/agent 动作数)²，关卡按难度 1:2:3:4:5 加权。竞赛模式每关动作预算=人类基线 5 倍，超时判负。
- **内部推理/工具调用不计入动作数**——这是 harness 可以堆计算的制度性口子，也是所有 Top 方案的核心打法。
- DeepSeek V4 Pro：官方榜/社区榜/Kaggle **均无任何成绩**（V4 Flash 只有 AGI-1 89.0%/AGI-2 61.4%）。底模在 AGI-3 上是零数据，真实水平只能实测。

### 1.4 Top 方案的共同模式（公开集打穿者怎么干的）

| 方案 | RHAE | 成本 | 核心设计 |
|---|---|---|---|
| Tycho | 100% | $2,986 | 多模态边玩边记观察日志；证据提炼成可执行世界模型（确定性 Moore 机），**证伪通过才用于规划**；agent 写的 Python 在断网 Docker 沙箱跑 |
| Retrodict | 99.86% | **$654** | **回溯验证**：每帧写 log.txt，用 Python 对历史帧做假说回测（错了零动作成本）；动作带 expect 预测；规则沉淀进跨窗口存活的 playbook.md |
| baseline1 | 99% | $400 | 构建并验证可执行 Python 世界模型再规划 |
| NOOA | 85.1% | $332 | NVIDIA：agent 即 Python 对象——方法是动作、字段是状态、docstring 是提示词 |
| OpenClaw（官方模板） | 5.2% | $2,912 | 开源 harness 基线 |

共同模式：①**文件日志优先**（log-as-memory）；②**Python 代码构建+证伪世界模型，省真实动作**；③文件系统做跨上下文记忆（playbook.md）；④成本 $300-$3,000 区间。

## 二、诚实基线判断（该反驳就反驳）

**问：QRA+V4 Pro 能不能干到 prime+Opus 5 的 95.5%？**

1. **不知道，且必须实测才有答案**。V4 Pro 在 AGI-3 零成绩；prime 的跨模对照证明同 harness 下底模差距 17-87pp。合理推测区间 5-30%（对照 OpenClaw 5.2%/DreamTeam 38.1%），接近 95% 需要 V4 Pro 底模接近 Opus 5 水平——当前证据不支持，但也不排除（V4 Pro 是我们日常实测很强的推理模型，AGI-3 类型题从没测过）。
2. **能确定的、也真正该追求的目标**：harness 乘数。prime 把 Opus 5 从裸测 30.2% 拉到 95.5%（乘数 3.2×）；arc-code 拉到 96.2%（同乘数）。**QRA 的考题是：我们的 harness 能把 V4 Pro 拉几倍？** 这个乘数才是"吸收 dsh/prime/pi 设计"的度量衡。
3. **公开集是免费的架构 benchmark**：接口是 pip 包、25 环境可重复跑、成本 $650-$3,000 量级、社区榜随时可提交。它测的恰好是我们要吸收的所有机制：长程记忆、上下文压缩、工具自组装、多环境隔离、假说验证循环——比 QRA-Bench 更适合度量 harness 层。**用它做 benchmark 驱动架构迭代，完全成立；用它"打满榜单"搏名次，不成立（榜首已满分，只剩成本前沿）。**
4. 决策：**挑战目标 = 公开集成本-性能前沿 + 乘数最大化；里程碑 = 上榜社区榜 + 争取官方验证通道（半私有集 ±15pp）**。Kaggle 弃赛（断网）。

## 四、作战计划（测量驱动，每步有分数回执）

### Phase 0：摸底（裸测 V4 Pro，~1 天）

1. `pip install arc-agi`，拿官方裸测提示词（技术报告 p.16 原文）用 V4 Pro 无工具直跑：先 2-3 个环境估成本，再全 25 环境出 RHAE 基线 + $ 成本。
2. 产出 `bench/arc3_baseline.json`（naked V4 Pro：每环境分数/动作数/成本）。
3. **决策门槛**（裸测 X%）：
   - X < 5% → 诚实目标定 20-40%（乘数 4-8× 存疑，harness 吸收优先级最大化）
   - 5% ≤ X ≤ 20% → 目标 40-70%
   - X > 20% → prime 级 95% 值得全压，Phase 2 全速
4. 预算红线：摸底成本 ≤ ¥100（成本周检 ¥350/周 的大头）。

### Phase 1：最小 harness（~1 周）

qra_arc 工具插件（env.step/reset/render/选格 → 工具，结果双写 logs.jsonl）+ 探索驱动（D1）+ B1 外部门 + B2/B3 prompt 方法论 + C1/C10 两个 20 行守卫。跑全量公开集，得到**乘数①**（naked→最小 harness）。目标：超 OpenClaw 5.2% 基线。

### Phase 2：机制吸收（按测量增量排序，~2-3 周）

每次只加一个机制、重跑全量、记录 RHAE 增量（benchmark 驱动架构迭代的正式闭环，仿 prime 的 ablate 逻辑）：
A2 压缩 → A1 日志强化 → C2 自组装 → C5 多环境并行 → C7 持久内核（D007 P2 借势落地）→ C6 技能双形态。

### Phase 3：成本前沿（~1 周）

C11 缓存隔离 + C8 便宜模型 + A4 剪枝账本。对标 Retrodict $654@99.86%——**如果我们的分数到不了 99%+，成本前沿比不过 Retrodict 也无妨，成本控制仍反馈到 QRA 主业务（量化研究成本周检）**。

### 里程碑与退出条件

- **M1（社区榜）**：公开集稳定分数 + 可复现 repo → 提 PR 上社区榜（无截止，随时）。
- **M2（官方验证）**：榜上 exceptional 被选中 → 半私有集 ±15pp 一致性 → 官方榜（顺带报销 $2,500）。
- **退出条件**：Phase 0 后若裸测 X% < 2% 且乘数连续两周无增量 → 战略收缩为"纯架构 benchmark，不上榜"（但机制吸收不停，收益全归 QRA 主业务）。

## 五、与 QRA 主业务的协同（重要）

ARC-AGI-3 这个 benchmark 意外地是 QRA harness 层的完美试炼场：
- **长程记忆/压缩**（A 簇）→ 量化研究的长会话回测、跨日报记忆；
- **假说验证循环**（B 簇）→ 研报的"可验证预测"闭环升级；
- **工具自组装**（C 簇）→ 未来"agent 给自己造因子工具"的基础；
- **成本控制**（Phase 3）→ 成本周检的实战化。

即：**打榜是训练场，机制吸收的收益全落回量化研究主业务。** 这也回答了"为什么不追 ARC 榜"旧结论与新目标的兼容——旧结论反对的是"搏名次"，新目标追求的是"用 benchmark 磨 harness，同时诚实上榜"。

## 六、风险

1. **V4 Pro 底模在 AGI-3 可能极弱**（GLM 8.6% 先例）→ Phase 0 摸底是第一道闸。
2. **API 成本失控**（Tycho $2,986 单跑）→ 预算红线 + B5 goal 预算 + Phase 3 成本机制。
3. **公开集成绩不迁移半私有集**（官方明说公开集更难、±15pp 容差反向）→ M2 前不预设结果。
4. **她/我方时间**：主业务（MES/PACK、述职、投资）优先，ARC 是夜间/周末项目——Phase 1 起就该照这个节奏排。
