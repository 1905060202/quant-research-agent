## D-01 工具行：整行染绿 + JSON 直出 → 分段着色 + 结构化摘要

**叙事版**：以前一行工具从头绿到尾，参数是 JSON 原文——`{"symbol": "600519", "days": 30}` 这样一大坨糊在行中间，扫一眼找不到工具名。现在只染图标和名字（亮青色），参数压成 `symbol=600519 days=30` 的浅色小字，耗时和结果尾巴也各自分开，绿 ✓ 红 ✗ 一眼定位成败。

**专业版**（同脚本 `/tmp/capture_tool.py` 在两棵树各自渲染）：

```
BEFORE: <ESC>[32m⏺ 工具 qra_quote {"symbol": "600519", "days": 30} · 0.0s · ✓ · 结果 11 字 ▸<ESC>[0m
AFTER:  <ESC>[1;36m⏺ 工具 qra_quote<ESC>[0m<ESC>[2m symbol=600519 days=30<ESC>[0m
        <ESC>[2m · 0.0s<ESC>[0m<ESC>[1;32m ✓<ESC>[0m<ESC>[2m · 结果 11 字<ESC>[0m<ESC>[2m ▸<ESC>[0m
```

- 折叠态摘要行（`_tool_summary`）保持纯文本不变，`fold_list` 门禁标记 `⏺ 工具` 不破。
- `_compact_args` 规则：bool/int/float（`f"{v:g}"`）/短 str（≤32）/≤4 元素短列表内联
  `[600519, 000858]`；扁平 dict→`k=v` 空格连写；嵌套结构 JSON fallback；总长 140 截断加 `…`。
- 单测：`CompactArgsTests` 5 条（空/扁平/短列表/嵌套回退/截断）全绿。

## D-07 浅色主题色重映射

**叙事版**：dim yellow 在白底终端上白晃晃看不清。现在启动时探测终端背景（OSC 11），
浅色底自动把金色系重映射成深琥珀系——白底也能读。

**专业版**：

- `palette.remap` 全表照抄 vendor cli.py `_LIGHT_MODE_REMAP` 12 键
  （#FFD700→#9A6B00、#FFBF00→#8A5A00、#B8860B→#5C4500、#c9d1d9→#24292F…），
  exact→upper→lower 三档查表（表里有小写键 `#c9d1d9`）。
- 探测协议：DA1 哨兵 → OSC 11 查询 → 亮度 >0.5 判浅色；在临时 raw 窗口期执行
  （tcsetattr 前后还原 termios）；`tcgetattr` 对非法 fd 抛 ValueError（非 OSError），已捕获。
- env 覆盖链：`QRA_TUI_LIGHT` > `HERMES_TUI_LIGHT` > `QRA_TUI_THEME` > 探测 > 默认暗色。
- 单测：`test_palette.py` 16 条（env 链/remap 全表逐键/大小写不敏感/暗色恒等/探测短路/非 tty）全绿。
