| 系统 | 总分 | 幻觉率 | 平均时延 | 令牌（30题合计） |

## 二、环境差异（如实记录，不做公平性伪装）

| | QRA | Claude Code |
|---|---|---|
| 行情 | qra_quote 直连新浪 | 读 `.hermes/plugins/qra/quote.py` 源码后用 Bash 直调 handler，结果一致 |
| 信号 | qra_signal 工具 | 翻 `latest_signal.json` 源文件，还核实了全池 134 板块（hot+neutral+cold） |
| 知识库 | qra_kb_fts 检索 | 直接读 kb_sources/*.md，引用到行号（如 CHEETAH_V1_EVOLUTION.md:23-27） |
| 记忆判重 | qra_memory_add 工具 | 读 qra_memory 插件源码，走真实 provider 调用路径，正确报告判重（且未污染真实库） |
| 验证账本 | qra_verify 工具 | 无此工具，R09 用文件读回自证 |

两种路径都成立：QRA 靠"定制工具即环境"，CC 靠"通用能力渗透环境"。这正是对比的意义。

## 三、缺陷清单：7 个全是评分器/gold 缺陷

1. **捏造检测误杀描述性数字**（T02/R06 各 0% 误判）："6 位数字"、"134 个板块"、"top_n 默认 10"、信号分数 0.7537 等工具回显被当捏造。修复=价格语境锚定（现价/涨跌幅/元/%），4 自测用例全过。
2. **文档引用白名单过窄**（R01 67%）：agent 引 cheetah_improvement_v2.md（更贴题）但不在预设 5 篇里。修复=引用任一真实 KB 文档即得分。
3. **涨跌幅符号处理**（R03 75%）："收跌 0.98%"的正数形态，符号活在"跌"字里。修复=反向符号仅在答文含"跌"时接受。
4. **K08 gold 要素猜错**（50%）：实际文档是 ES-SOP L1 门禁 5 项检查（新鲜度/一致性/alpha/衰减/模拟盘），不是预测-验证-复盘-登记。
5. **日期文件名误判文档幻觉**（R04/R05）：agent 写的 reports/daily/2026-08-14.md 被当引用不存在文档。修复=日期文件名豁免。
6. **MD 正则不含点号**（CC R07 误判）：`research_methodology_v2.1_multi_hypothesis.md` 在 "v2.1" 处被截断成 "1_multi_hypothesis.md"。修复=字符类加 `.`。
7. **R03 要素过字面**（CC 75%）：CC 说"冷区"，gold 只认"冷榜"。修复=要素放宽为"冷"。

## 四、bench 的诚实边界

- **鉴别力有限**：两系统全对，说明 v1.0 度量的是"基础胜任"（工具正确性/错误诚实/KB 召回/研报结构），不区分能力上限。本轮目的本来就是回归式验收（W1-W4 重建的能力是否工作），达标；若要能力对比，W9-12 需加**难题层**（多步歧义/对抗性错误/长程记忆）。
- **铁证抽查**：R09 文件实写含价格、T08 判重词（duplicate_of）、K10 引用 methodology_family_v1.md×5、R02 行情与基准一致、16 题双系统硬断言抽查全过。分数可信。
- **排名口径**：gold 对齐工具上报的全池 134 板块全局排名（白酒Ⅱ=98），不是冷榜位置 7。
- **CC 侧成本无账**：claude -p 无 --usage-file 等价物，成本对比缺席，如实声明。
