# W3-4 · AutoGen 量化研究小组完成记录（2026-08-14）

## 做了什么

按论文 2308.08155 的三个锚点落地（autogen-agentchat 0.7.5）：

1. **三人小组**：行情分析师（market_query 工具）/ 方法论文献员（kb_search 工具）/ 研究员（汇总+TERMINATE），RoundRobinGroupChat 轮流发言
2. **人类检查点**：研究员结论过确定性门槛（长度/工具错误字样）才落盘 `reports/team_daily.md`——论文 human proxy 的 approval gating
3. **对比实验**：同一任务 LangGraph 单 agent vs AutoGen 小组

## 对比实验结果（2026-08-14 实测）

| 任务 | LangGraph 图式 | AutoGen 对话式 |
|---|---|---|
| 单域：比亚迪行情 | 5.1s / 工具 1 次 | 4.7s / 工具 1 次（librarian 冗余发言"文档库无股价"） |
| 跨域：茅台行情+方法论理由 | 27.9s / 工具 2 次 | 5.3s / 工具 2 次，文档引用带编号 |

**读法（不夸大）**：
- 跨域任务小组优势真实存在：分工并行 + 角色 prompt 隔离（分析师的行情输出不污染研究员的方法论归纳）
- 单域任务小组是负资产：多出来的角色发言 = 多花的 token 和时间
- ⚠️ 时延对比有混杂因素：小组用 deepseek-chat（非思考模式），LangGraph 用 v4-flash（thinking）——"快 5 倍"不能直接归因于编排方式。这也是为什么小组要换非思考模型（见 bug 3）

## 调试记录（4 个真实 bug）

1. **非 OpenAI 模型名缺 model_info**：OpenAIChatCompletionClient 对 deepseek-v4-flash 抛 "model_info is required" → 显式传 {vision, function_calling, json_output, family}
2. **Anthropic 端点拼 OpenAI SDK 404**：llm.py 的 base_url 是 `…/anthropic`，拼 `/v1` 后请求打到 `anthropic/v1/chat/completions` → 剥后缀再拼
3. **thinking 模型自我独白被当结论落盘**：v4-flash 的推理流混进 content，researcher 的"内心独白"进了 team_daily.md → 小组换 deepseek-chat + 提取策略改"最后一条"而非"最长一条"
4. **FunctionTool 单 dict 签名接不住 kwargs**：框架按函数签名拆参，`search(args: dict)` 收到 `search(query=…)` 报参数格式错误（librarian 在结论里诚实报告了这个失败）→ 加签名明确的薄包装

## 面试弹药（编排选择判断）

1. **什么时候选图式（LangGraph）**：流程固定、步骤可预期、要审计每一步（数据采集→验证→入库这种 pipeline）；状态转换必须显式
2. **什么时候选对话式（AutoGen）**：角色分工清晰的任务、人类要介入检查点、流程本身不确定需要协商
3. **多智能体 ≠ 免费的正确性**：小组放大 token 成本（每轮三个 agent 都读全上下文），必须配终止条件（max_turns + TERMINATE）和门槛（检查点）；我们的评审门/claims 账本就是手工版
4. **工具契约要跟框架对齐**：同一批工具（registry），LangGraph 手写 JSON 解析传 dict，AutoGen 按签名拆 kwargs——跨框架复用要薄包装
