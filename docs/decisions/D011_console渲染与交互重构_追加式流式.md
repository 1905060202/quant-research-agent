# D011 · console 渲染与交互重构（追加式流式渲染器）

- 日期：2026-08-16
- 状态：accepted（v3 增补：鼠标捕获陷阱 + 异常兜底落盘 + 菜单 Enter 语义定稿）
- 触发：雅宁实测 console 体验问题清单——输出大量重复、屏幕不自动跟随下移、
  `/` 输入无提示、输出无折叠不可点开、CoT 被框起来太死板、无活动反馈（不知道
  是卡死还是在思考）、subagent 不可见。
- v2 增补（2026-08-16 晚间，雅宁第二轮实测）：
  1. **输出时打字 → 终端崩**。根因：rich Live 渲染线程与 InputLayer 回显是
     两个不同步的 tty 写入者，回显字节可插进 Live 转义序列中间 → 终端模拟器
     CSI 状态机卡死（花屏/假死）。pt/pty 复现不崩是因为 pty 侧没有转义解析器，
     崩溃只发生在真实终端模拟器上。**修法：单一写入者 TermIO**（本 ADR §1 增补）。
  2. **←→ 光标移动缺失**。原列「明确不做」——用户明确要求，移入 P0：
     LineBuffer 行编辑模型 + 光标移动/行中插入删除/Home/End（本 ADR §3 增补）。
- v3 增补（2026-08-16 深夜，雅宁第三轮实测）：
  1. **无法复制输出 / 无法滚轮翻页**。根因：为点击折叠常开的 SGR 鼠标捕获
     （`\x1b[?1000h`）吞掉终端原生拖选与滚轮事件。**修法：默认不捕获鼠标，
     `/mouse on` 显式开启**（iTerm2 按住 Option 可临时拖选），§2 增补。
  2. **回合报错后 console 假死 + 错误现场拿不到**。根因：渲染线程与主循环缺
     异常兜底（终端 raw 模式残留 = 「戳了错误之后无法运行」），且错误只印在
     无法复制的终端上。**修法：渲染/主循环三层 try/except + emergency_note +
     回合异常落 `HERMES_HOME/logs/console_errors.log`（traceback 全文）**，§1 增补。
  3. **菜单 Enter 语义定稿**：首版「Enter 只补全不执行」实测判定为错误 UX
     （`/help↵` 什么都不跑，与 CC/prime 相悖）。**定稿：Enter=选中即执行，
     Tab=只补全**，§3 增补。

## 问题根因（实测定位）

1. **重复输出 + 不滚动**：`main.py` 用 rich `Live` 全帧重绘
   （`vertical_overflow="visible"`）。Live 的机制是「光标上移 N 行 → 整帧重印」，
   当渲染内容（流式 CoT）长到超过终端高度时，上移行数与实际不符，帧与帧互相
   覆盖、同样内容被重复打印，且终端永远不发生自然滚动——两个症状同源。
2. **`/` 无提示**：InputLayer 只有 Tab 补全（且要手动按），没有 CC 式的
   live 命令面板。
3. **输出死板**：CoT 用 `Panel` 框（box.ROUNDED），工具块用边框面板、结果
   全文展开 3000 字符——与 CC/prime 的「灰暗思考 + 一行摘要 + 点开看全文」相反。
4. **无活动反馈**：只有首 token 前有一个等待帧；长工具执行期间屏幕静止。
5. **subagent 不可见**：delegate_task/qra.run 子代理只有一条工具日志。

## 决策

### 1. 追加式流式渲染器（废弃 rich Live）+ 单一写入者

新模块 `src/qra/console/renderer.py`，原则：

- **已定型内容只 print 一次**——自然滚动（终端自动跟随）、scrollback 完整、
  从结构上消灭重复帧。
- **唯一原地刷新的是活动尾部**：一行 spinner（`\r` 原地重画，0.1s 心跳），
  内容到达先擦 spinner 再追加。
- CoT：**无框**。灰暗（grey62）逐 token 流式追加；块头 `✻ 思考`、
  块尾 `✻ 思考 · 用时 12s`（CC/prime 风格：计时不追求逐秒刷新，闭合时给总数）；
  spinner 文案带活计时（`⠋ 思考中…（3s）`）提供「没卡死」反馈。
- 文本块：流式期间按原样追加（markdown 半成品不转换），块闭合时区域重印为
  渲染后的 Markdown（沿用 rich Markdown）。
- 工具块：默认折叠为一行
  `⏺ 工具 name(args摘要) · 1.2s · ✓ · 结果 234 字 ▸`；
  子代理（delegate_task/spawn*）标题为 `⎇ 子代理`。
- usage footer 保留（含 ¥，测试标记依赖）。
- **单一写入者 TermIO**（`src/qra/console/termio.py`）：锁 + 构造时刻绑定的
  真实 stdout 文件对象；渲染帧 / spinner / 输入回显 / 菜单 / 提示符全部经它
  串行写出——字节流不可能再在转义序列中间交错（打字崩终端根因修复）。
  回合内 redirect_stdout（main.run_turn 既有机制）不影响 TermIO 绑定。
- 回合中输入回显**静音**（缓冲到回合结束再 redraw）：既避免打断渲染流，
  也符合「回合中敲入先缓冲」的既有语义；鼠标点击与 Ctrl+T 走事件队列直达渲染器。

### 2. 折叠与点开（SGR 鼠标 + 键盘回退）

- 渲染器维护**行账本**：每个块记录 (id, 种类, 起止屏行, 折叠态, 全文)。
  行数用同宽度测量 console 计算（wrap 感知）。
- 点开/收起 = 区域重印：光标上移（块下方行数）→ 重印该区域 → 光标下移复位。
  只有被点块和它下方的区域被重印，上方已定型历史不动。
- **SGR 鼠标**：**默认不捕获**（常开会吞掉原生拖选复制与滚轮——v3 实测坑）；
  `/mouse on` 开 `\x1b[?1000h\x1b[?1006h`，`/mouse off`/退出还原；InputLayer 的
  CSI 状态机扩展接受 `<` 引入符与 `M/m` 终止符，解析出 (按钮, 行, 列)；
  左键按下（Cb=0）触发。回合中点击进渲染事件队列由渲染线程处理；
  提示符阶段由主线程直接处理（同一 renderer，加锁）。
- 键盘回退：`/fold` 列块表（编号/种类/名称/折叠态），`/fold <n>` 切换第 n 块
  （无鼠标终端可用）。
- 已知边界（诚实记录）：点击展开是对「已渲染区域」的重印，滚动条位置之外的
  点击在部分终端里可能偏行（终端高度变化引起）；v1 不做整屏 TUI。

### 3. 斜杠命令面板

- InputLayer 新增 `menu_provider(draft) -> [(名称, 描述)]`；draft 以 `/` 开头
  且无空格时即弹出面板（提示符下一行起，反显高亮当前项），随输入过滤。
- ↑↓ 在面板打开时导航面板（关闭后恢复历史导航）；**Enter 选中即执行**
  （v3 定稿：补全进草稿 + 立即提交；`/help↵` 直接跑）；Tab 补最长公共前缀
  （只补全不执行，留给用户补参数）；Esc 关闭；其他字符继续过滤，无匹配自动关闭。
- 面板重绘 = 原地重写面板行 + 回到提示符行重印 prompt+draft。

### 4. subagent 可见性

- 工具行 `⎇ 子代理` 前缀区分 delegate_task 类工具。
- 新命令 `/agents`：读 `agent.subagent_lifecycle._REGISTRY.records`
  （同进程子代理：state/started/completed），列出当前会话的子代理快照。
- qra_python 内核侧子代理在 `qra.run` 的回执与 `list_subagents` 可见（内核会话
  内），console 侧如实提示。

### 5. 明确定不做的（P1 滚动清单）

整屏 TUI（prime pi-tui 式）/ Ctrl+C 真中断 agent.interrupt / todo 面板 /
plan mode / skills UI / hooks UI。理由：本轮聚焦体验主路径，
追加式渲染是这些功能的地基，先立地基。
（v2：←→ 光标编辑已从本清单移入 P0。）

## 兼容与风险

- pty 门禁标记不变：`思考`（块头）/ `工具`（折叠行）/ `¥`（usage）都在新渲染
  输出里；命令 pty 六用例不动，另加 `/` 面板与 `/fold` 两条离线用例。
- 单测新增：renderer 行账本/折叠行格式/区域重印行数守恒、菜单过滤与导航、
  SGR 解析纯函数。
- rich 只保留 Console/Text/Markdown，移除 Live/Panel 依赖（main.py 瘦身）。
- 流式期间 markdown 半成品按原文显示——与 CC 的「流式渲染 markdown」有差距，
  已在 ADR 记录，P1 可做段落级 markdown 流式。
