# D003：QRA-Bench 动态 gold + 机械评分（拒绝 LLM-as-judge）

- 状态：accepted
- 日期：2026-08-14

## 背景

评测需要 gold 答案。行情类题目若硬编码数值，价格随时间衰减（今天 1341.99 明天就变了），
评测跑一次错一次。同时 LLM-as-judge 引入裁判幻觉和不可复现。

## 决策

- 数值 gold = 开跑前工具快照：baseline.json + 每题开跑前重采行情（防跨题漂移）
- 评分 = 纯机械规则（14 种 gold 类型 0/0.5/1），无 LLM 裁判
- 幻觉率双口径：价格语境锚定的捏造断言 + 引用不存在文档（日期文件名豁免）

## 备选项

- 硬编码 gold：价格时间衰减，周周误报
- LLM-as-judge：复现性差、裁判幻觉、口径漂移

## 后果

- 评测可任意时刻复算（W6 全程从零测）
- 成本：每题多一次行情采集；信号类题目依赖工具口径（rank=全局排名而非榜单位置，
  T06 为此误报过一次，口径已写进 README）
- bench v1.0 只量基础胜任（两系统 100% 无区分度），能力对比需难题层——诚实边界
