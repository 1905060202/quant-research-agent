# QRA 量化研究日报

一条流水线：**信号 → 行情 → 方法论 → 持仓 → 撰写 → 验证**。目标是可日常使用的日报生产系统（服务副业，学习时间即工具投资）。

## 流程（按顺序，每步都做）

### 1. 信号层

```text
qra_signal（不带参数）——拿今日 HOT/COLD 榜
```

记下 top 3 热板块和 top 1-2 冷板块的名字与分数。注意工具返回的 `model_is_stale` 标记：信号模型过期超过阈值时要如实写进日报"数据质量"段，不许假装新鲜。

### 2. 行情层

对 top 3 热板块各挑 1 个有代表性的龙头标的，用 `qra_quote` 查实时行情。涨跌幅、价格、日期时间都要进日报。行情取不到（停牌/代码错）就诚实标"无数据"，不许编数字。

### 3. 方法论层

对当日最值得说的板块/现象，用 `qra_kb_fts` 检索方法论知识库（例：查询"回撤"、"趋势"、"情绪"等主题词）。检索到的原则要**引用出处**（命中的文档名），放进"方法论依据"段。

### 4. 记忆层

用 `qra_memory_search` 查最近相关的市场记忆（例：查询"茅台"、"新能源"、持仓相关标的）。有上期预测的，调出来准备写验证卡。有值得长期记的新事实，用 `qra_memory_add` 记一条（工具自己会去重）。

如果 qra_memory 工具不在（cron 环境记忆被跳过），跳过本层并在"数据质量"段注明"记忆层不可用"。

### 5. 撰写

写文件 `reports/daily/YYYY-MM-DD.md`（日期取今天，相对路径以项目根为基准）。结构固定：

```markdown
# 量化日报 YYYY-MM-DD

## 今日信号
（热冷榜，板块名+分数，注明信号模型日期）

## 龙头行情
（每只：名称 现价 涨跌幅 数据时间）

## 方法论依据
（引用：<文档名> 说 ……）

## 持仓相关
（涉及用户持仓的话；没有就写"无直接相关"）

## 数据质量
（模型过期/行情缺失等一切不新鲜之处，如实列）

## 验证卡
### 上期预测复盘
（读上期日报的验证卡段，逐条：预测 → 实际 → 对/错。
  上期日报不存在就写"首期，无上期预测"。）
### 本期预测登记
（本期给出明确、可验证的预测，每条一行。例子：
  - "预测：明天 X 板块继续强于 Y 板块"（验证方式：明日信号榜对比））
```

**铁律**：数字必须来自工具返回，不许凭空写；拿不到就写拿不到。

### 6. 验证

用 `qra_verify` 登记声称并立即检查：

```text
qra_verify action=claim check_type=file_contains
  check_args={"path":"reports/daily/YYYY-MM-DD.md","pattern":"验证卡"}
claim_text="日报已生成且含验证卡段"
```

再对日报里引用的关键行情数字抽 1-2 个登记 `data_quote` 检查（symbol=对应代码）。检查失败就修数据或诚实撤回——回合末守卫会拦你，别等它拦，自己先过一遍。

## 完成标准

日报文件存在 + 验证卡段齐全 + qra_verify 账本里本期声称全部 passed。
