# QRA-Bench v0.1 评测报告 · 2026-08-14

## 一句话结论
QRA（自研量化研究 Agent）在自建垂直评测集上 **97%**，同题 Claude Code **81%**——QRA 领先 17pp。
但**这个对比有重要前提**：Claude Code 没有我们的内部知识库和行情接口（环境劣势），
且 QRA 在通用任务上远不如 Claude Code（Claude Code 有真实工具链/子代理/钩子）。
**结论：QRA 的领先 = 垂直领域（行情接口+方法论库+领域知识）带来的优势，不是通用能力超越。**

## 评测设计
- 任务集：13 题 × 3 域（工具5/知识3/研究5）——垂直场景真实任务
- 评分：客观 gold 标准（数值/要素/结构），0/0.5/1
- 对比：Claude Code 2.1.231 同题跑分（cat pipe 模式）

## 结果
| 域 | QRA | Claude Code | 差距 |
|---|---|---|---|
| 工具调用 | 93% | 60% | +33pp（QRA 有真实行情接口） |
| 知识检索 | 100% | 83% | +17pp（QRA 有方法论库） |
| 研究输出 | 100% | 100% | 平 |
| **总分** | **97%** | **81%** | **+17pp** |

## 迭代记录（首轮 → 二轮）
首轮 77% → 修复 3 bug → 二轮 97%（+21pp）
1. 【T05 多标的失败】LLM 一次只调一个工具 → 支持多工具调用解析+并行执行
2. 【K03 知识库缺词】验证卡不在方法论库 → 新增 data/qra_kb/ 知识源
3. 【R01 工具调用泄漏】JSON 混在正文 → 解析升级（提取含工具名片段）

## 已知缺陷（诚实记录）
- **T05 稳定性 67%**：LLM 偶发返回空（3次中2次成功）——多工具并行不可靠，需重试机制
- R02 偶发 13.8s 长延迟（多轮检索）
- 无 LLM 幻觉率指标（需接入事实核查子代理——P2 项）
- 评测集仅 13 题，样本小，结论置信度中等

## 与四 agent 对比的真实定位
- **无法与 prime-agent/DSH/Claude Code 直接比通用能力**——它们有完整工具链+子代理+文件系统访问
- QRA 当前 = 单 agent + 2 工具 + 方法论库（垂直场景专用）
- 真实差距：Claude Code 有 40+ 工具/子代理并行/钩子系统/文件访问；QRA 只有 2 工具
- **QRA 的优势仅在垂直领域**：行情接口即时可用、方法论库私有命中率高、领域 prompt 定制

## 下一步（提升真实水平，不粉饰）
- P1: T05 重试机制（空响应自动重试）→ 稳定性 67%→95%+
- P1: 接入 Chroma 向量检索（bigram → 向量）→ 召回质量
- P2: 幻觉率评测（事实核查子代理）→ 建立第三指标
- P2: 扩评测集至 30 题（含错误输入/边界情况）
